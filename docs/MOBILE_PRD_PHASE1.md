# Mobile Scope

Mobile mencakup authentication/profile, dashboard, cuti, approval cuti, attendance, task, history, GPS validation, device security checks, dan face matching on-device.

Release hardening yang masih ditunda:

- Play Integrity verification di backend.
- App Attest/DeviceCheck verification di backend.
- Face verification server-side.

Client-reported device metadata adalah telemetry, bukan bukti attestation kriptografis.
